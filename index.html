College Java Micro-Project Overview

Architecture, technical specifications, and key learning concepts

1. Client-Server Architecture

The application follows a clean REST architecture. The HTML5/CSS3/JavaScript frontend communicates via asynchronous fetch() requests with a lightweight Java HTTP server built using com.sun.net.httpserver.HttpServer.

2. Zero External Dependencies

Engineered strictly with Core Java (JDK 21/17). No external frameworks like Spring Boot or third-party JSON libraries (Jackson/Gson) are required, making it easy to explain in college viva reviews.

3. Dual-Layer Validation

User inputs (empty fields, non-numeric values, negative numbers, and current readings smaller than previous readings) are verified instantly in the client and strictly validated in Java with standard HTTP status codes (200, 400, 405, 500).

4. Progressive Slab Algorithm

Units are partitioned progressively into tiered brackets: Tier 1 (1–100 @ ₹2), Tier 2 (101–200 @ ₹3), and Tier 3 (>200 @ ₹5), correctly calculating cumulative energy charges.
